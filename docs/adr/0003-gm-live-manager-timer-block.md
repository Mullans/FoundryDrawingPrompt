# GM live manager timer block (summary row)

Live Drawing Prompt Manager timer UI is one **timer block** on the right of the summary row (with prompt quote + drawing name on the left)—not a separate row below the summary.

Layout (upside-down T): countdown chip stacked over Pause/Reset/Stop; −2m/−30s as the left wing; +30s/+2m as the right wing. When a timer is active, the readout lives in that same block as the transport controls. Dimensions leave the summary bar and are not shown as a preview corner readout (GMs already set canvas size explicitly; Prompt-canvas dims are wrong for Full Framing).

Source: Jul 20 UI/UX grill (recorded here so chat decisions are not tribal knowledge). Supersede this ADR if a later grill explicitly replaces the layout.
